# Aplicar a pesquisa de várias músicas

Esta atualização é para a versão `RiffLab-Windows-musicas-singles.zip` ou para a versão anterior depois de aplicar `RiffLab-atualizacao-musicas-singles.zip`. Para instalação nova, use o ZIP completo correspondente.

1. Feche o RiffLab.
2. Extraia este ZIP em uma pasta temporária.
3. Copie o conteúdo da pasta `RiffLab` extraída para a pasta existente do RiffLab, onde estão `INICIAR.bat` e `main.py`. Mescle as pastas e confirme a substituição dos arquivos. Não apague a pasta antiga.
4. Abra `INICIAR.bat`. Veja `PESQUISAR-VARIAS.md` para usar a novidade.

A atualização não contém configuração, cookies, banco de dados, ambiente Python, Deno, executáveis de ferramentas ou músicas. Não apague esses arquivos.
