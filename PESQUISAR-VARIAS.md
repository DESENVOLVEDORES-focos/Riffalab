# Pesquisa normal e pesquisa de várias músicas

Na tela **Pesquisar música**, escolha uma das duas abas:

- **Pesquisa normal**: digite uma música, artista ou link e clique em **Pesquisar**.
- **Várias músicas**: digite uma pesquisa por campo, use **+ Adicionar música** para acrescentar campos e clique em **Pesquisar todas**. Os campos vazios são ignorados. A lista de campos rola quando for longa.

Cada pesquisa múltipla aparece em sua própria seção, na ordem dos campos, assim que terminar. Um erro aparece apenas na seção afetada. Role a área principal para ver todos os resultados; não existe uma pequena área de resultados separada dentro de cada seção. Os campos de pesquisa são recolhidos automaticamente para dar espaço: use **Editar pesquisa** para vê-los novamente. **Fontes / ordem** permite mostrar as opções de fonte e ordenação.

Marque **Incluir** nos resultados desejados e clique em **Adicionar a Downloads**. Isso não inicia o download. As marcações continuam disponíveis entre buscas e são salvas localmente. Se o mesmo vídeo aparecer em mais de uma seção, as marcações ficam sincronizadas. **Selecionar os melhores** usa a quantidade escolhida para todos os resultados visíveis, não para cada seção.

## Formatos de áudio

Os formatos são consultados em segundo plano. A lista deixa de mostrar apenas **melhor áudio disponível** assim que um método retorna formatos reconhecidos; os demais continuam em andamento e podem acrescentar informações. O cartão informa quantos métodos terminaram. Clique em **ver detalhes** para conferir o estado e os motivos dos quatro métodos e em **Comparar formatos** para ver os IDs e os dados técnicos conhecidos e escolher um formato. Uma escolha feita durante a consulta é preservada.

Os primeiros resultados das seções diferentes recebem prioridade na fila. Consultas podem demorar, especialmente com muitas músicas. Se nenhum método conseguir detectar áudio, o cartão mostrará o aviso e permitirá **tentar de novo**. Não são inventados formatos ou bitrates. Cookies, bloqueios, versões do yt-dlp, desafios JavaScript ou mudanças do serviço podem impedir a consulta. Não compartilhe cookies, chaves ou URLs privadas ao relatar uma falha.

O aplicativo foi testado em Linux com Qt offscreen e respostas simuladas, além de yt-dlp com servidor HTTP local. Não houve teste desta versão no Windows nem em pesquisas reais no YouTube nesta sessão.
