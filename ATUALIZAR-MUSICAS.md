# Atualizar o RiffLab

Esta atualização incremental é para a versão `RiffLab-Windows-pasta-saida-corrigida.zip` (ou para a versão anterior após aplicar `RiffLab-correcao-pasta-saida.zip`). Para uma instalação nova, use o ZIP completo.

1. Feche o RiffLab.
2. Extraia o ZIP da atualização em uma pasta temporária.
3. Copie o conteúdo da pasta `RiffLab` extraída para sua pasta existente, onde ficam `INICIAR.bat` e `main.py`. Mescle as pastas e confirme a substituição dos arquivos. **Não apague a pasta antiga.**
4. Abra `INICIAR.bat`. Consulte `NOVIDADES-MUSICAS.md` sobre as mudanças.

A atualização não inclui config.json, cookies, banco de dados, ambiente Python, Deno, ferramentas executáveis ou músicas; não os apague. O antigo modelo padrão de organização é migrado para artista/título e modelos personalizados são mantidos. Arquivos de áudio antigos não são movidos.
